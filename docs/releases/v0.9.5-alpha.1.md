# v0.9.5-alpha.1 - Backtest Diagnostics & Strategy Report

Release date: 2026-05-30

## What Changed

- Added a backtest diagnostics contract for run results.
- Added Strategy Report data for risk, trade distribution, warnings, and stability segments.
- Added optional diagnostics to run detail and run result API responses.
- Added exportable `strategy-report-{runId}.json` artifacts.
- Added a frontend Strategy Report section on run detail pages.
- Added diagnostics fields to run comparison views.

## Safety

- Backtest diagnostics are research artifacts, not trading signals.
- Strategy reports do not imply production readiness.
- Real order submission remains disabled by default.
- Testnet/backtest validation is not production exchange certification.

## Validation Notes

- Validate Python diagnostics edge cases: empty trades, only losses, only wins, drawdown, segmentation, and warnings.
- Validate Java/Python diagnostics payload compatibility.
- Validate old runs without diagnostics return successfully with `diagnostics` omitted.
- Validate frontend run detail and compare views with present and missing diagnostics.
- Validate report artifact export includes diagnostics, warnings, generated timestamp, and the safety note.

## Rollback Notes

- This release stores diagnostics in existing JSON result/artifact payloads and does not require a schema migration.
- Rollback can redeploy the previous image/tag after preserving any generated run artifacts needed for audit.
